# Python Projects

A collection of beginner-friendly Python programs built while learning programming fundamentals, Linux administration, networking, and cloud concepts.

## Projects

| Project | What it demonstrates | Run |
| --- | --- | --- |
| `DiceRoller.py` | Random numbers and console input | `python DiceRoller.py` |
| `cloud_cost_estimator.py` | Input validation, functions, and simple cloud-cost calculations | `python cloud_cost_estimator.py` |
| `system_info.py` | Cross-platform system inspection with Python's standard library | `python system_info.py` |

## Getting started

1. Install Python 3.10 or newer.
2. Clone this repository.
3. Run any project with `python <file-name>.py`.

These examples use only Python's standard library, so no packages need to be installed.

## Learning goals

- Write clear command-line programs
- Validate user input and handle errors
- Explore Linux and networking foundations responsibly
- Build practical cloud-computing intuition
